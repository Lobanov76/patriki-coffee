# Патрики — сайт кофейни в Ташкенте

Концепт-сайт для сети кофеен «Патрики» (Ташкент, открыто 24/7): живое видео на первом экране,
неоновая вывеска, история, цитаты с меловой доски, отзывы гостей, меню с фото и адреса.

## Что внутри

- `index.html` — структура и тексты страницы
- `styles.css` — оформление, адаптивность под телефон, анимации
- `script.js` — появление блоков при прокрутке, бесконечные ленты цитат и отзывов, «подмигивание» неона
- `img/`, `video/` — фото и видео

Сайт сделан на чистом HTML, CSS и JavaScript, без сборщиков и фреймворков.

## Как открыть локально

Дважды кликнуть по `index.html` или запустить локальный сервер:

```bash
npx serve .
```

- Фото кофейни — снимки гостей с Яндекс Карт.
